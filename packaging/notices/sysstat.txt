sysstat: parts of clifr's sar and iostat

clifr's sar prints sar's reports as sar -f prints them from a daily file,
as sysstat (https://sysstat.github.io, https://github.com/sysstat/sysstat)
11.7.3, 12.5.x, 12.6.1 and 12.7.7 do. Parts of clifr's Go code follow
sysstat's C code, written anew in Go:

- internal/query/sar.go: the reports' column titles (activity.c's
  hdr_line), the header line and its repetition (print_hdr_line,
  check_line_hdr, handle_curr_act_stats), the first line
  (print_gal_header, print_report_hdr), LINUX RESTART (print_sar_restart),
  the per-report reading of a file's records and their averages
  (read_stats_from_file, write_stats, write_stats_avg), the values and
  formats of the CPU (print_cpu_stats, print_oneline_cpu_stats,
  get_global_cpu_statistics, get_per_cpu_interval), task creation and
  context switch, interrupt, swapping, memory and swap space, huge page,
  kernel table, queue, CPU pressure, network interface (with
  compute_ifutil, check_net_dev_reg, check_net_edev_reg), NFS client and
  server, socket, IP, ICMP, TCP and UDP (v4 and v6) and file system
  reports (pr_stats.c), and what sadc reads for them (rd_stats.c:
  read_loadavg, read_kernel_tables, read_net_nfs, read_net_nfsd,
  read_net_sock, read_filesystem); the number formats (common.c:
  cprintf_f, cprintf_u64, cprintf_xpc).
- internal/query/iostat.go and the device order in internal/query/system.go:
  iostat's reports and options (write_stats, write_disk_stat_header,
  write_plain_cpu_stat, write_plain_basic_stat, write_plain_ext_stat,
  write_ext_stat, write_sample_timestamp, rw_io_stat_loop; rd_stats.c:
  compute_ext_disk_stats), from iostat.c (11.7.3, 12.5.2, 12.7.7).
