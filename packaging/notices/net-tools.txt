net-tools 2.10: the text of `clifr netstat -s`

clifr's `netstat -s` prints each protocol counter in the sentence that
net-tools' netstat prints for it (for example "%d incoming packets
delivered"), so that its output matches the real tool word for word. These
sentences and the section headings come from net-tools 2.10, file
statistics.c (https://github.com/ecki/net-tools, tag v2.10); clifr's code
that prints them was written anew in Go (internal/query/netstat_stats.go).
